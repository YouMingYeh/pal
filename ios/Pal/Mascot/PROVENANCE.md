Pal mascot resources supplied in pal-mascot-handoff-v1. Cloud.html adapts the MIT-licensed Bloub renderer by Jérémy Perret. See Bloub-LICENSE.txt. Static images are unmodified SVG renders at 512 pixels; light and dark SVG pairs are byte-identical. Native host supplies lifecycle, speaking motion, and offscreen pause.

Animated frames are sampled from the same supplied SVG engine at 192 pixels, preserving 64 sample times across four seconds. Native playback follows that sequence and its reversed interior at 16 fps (126 references, 7.875 seconds), closing the loop through adjacent samples without duplicating decoded images. The 32-point chat avatar uses a 48-point canvas (144 pixels on a 3× screen), so this raster size avoids upsampling.
